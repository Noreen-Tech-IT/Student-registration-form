# Student Registration Form

A simple and user-friendly **Student Registration Form** created using **HTML and CSS**. This project is designed to collect basic student information through a clean and organized web form.

## 📌 Features

* Student personal information fields
* Contact information fields
* Date of birth field
* Gender selection
* Course/program selection
* Address field
* Submit and reset buttons
* Clean and organized layout
* CSS styling and button hover effects

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure of the registration form.
* **CSS3** – Used to style and design the form.

The purpose of this project is to practice creating HTML forms and applying CSS styling. It is also part of my web development learning journey and helps me improve my front-end development skills.

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
